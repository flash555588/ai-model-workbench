# AI Model Workbench 0.7.8

`0.7.8` is a release-review patch for `0.7.7`.

## Changes

- Synced `package-lock.json` transitive dependency resolution so the packaged
  release passes the Obsidian plugin review's lockfile check.
- Added the `0.7.7` release notes file that was published after the `0.7.7`
  tag was cut.

## Behavior

- All functionality is unchanged from `0.7.7`.
- No settings or persisted-data migration is introduced.

## Verification

- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`
- `npm run verify:release`
