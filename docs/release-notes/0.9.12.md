# AI Model Workbench 0.9.12

This maintenance release includes the documentation and Obsidian review fixes
merged in PR #32, following the note workflow improvements in 0.9.11.

- Expand the English and Chinese README with recent updates, feature guidance,
  one-step note insertion and registered-part inspection.
- Add seven real Obsidian screenshots covering both insertion languages,
  inline and table embeds, note part displays, full inspection and the workbench.
- Use Obsidian element helpers for image and registered-part inspection placeholders,
  retaining their existing parent containers and canvas restoration behavior.
- Remove all four CSS important declarations. A CSS variable preserves sidebar
  resizing while responsive and collapsed layouts retain the correct grid.
  Selector specificity keeps unavailable actions hidden, including active secondary
  controls when the note toolbar is compact.

Existing embeds, saved part configurations and renderer routing remain compatible.
The release contains `main.js`, `manifest.json` and `styles.css` for installation.

## 中文说明

本次维护发行包含 PR #32 的文档更新和 Obsidian 审查修复，延续 0.9.11 的笔记体验升级。

- 中英文 README 补充近期更新、特色功能、一键插入及按已登记零件检查的使用说明。
- 新增七张真实 Obsidian 截图，展示中英文插入窗口、正文与表格嵌入、笔记零件展示、完整检查窗口和工作台。
- 两处占位元素改用 Obsidian 创建助手，保留原有父容器和画布返回逻辑。
- 移除四处 CSS important 声明；通过变量保留侧栏宽度调整，通过选择器优先级保证不可用控件隐藏，窄窗口与收起布局保持正常。

安装时将 `main.js`、`manifest.json`、`styles.css` 放入
`.obsidian/plugins/ai-model-workbench/`，然后重新启用插件或重启 Obsidian。
已有模型嵌入、零件配置及插件设置可继续使用。

## Verification

The underlying changes passed 438 tests across 64 files, type checking, lint,
the note preview harness and the full native Obsidian 1.13.7 regression run on Windows.
Native checks cover Chinese/English insertion, light/dark/narrow layouts, note
controls, image embeds, registered parts on Babylon and Three, pointer/keyboard
sidebar resizing and collapsed grids at 360, 480 and 768 CSS px.

Release metadata and installation assets are checked by `npm run build` and
`npm run verify:release`. GitHub Actions rebuilds and verifies the tagged source,
publishes SHA-256 hashes in the release notes and generates asset attestations.
