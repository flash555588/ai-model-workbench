# AI Model Workbench 0.9.11

This release includes the accumulated 0.9.0–0.9.11 improvements since 0.8.1.
Model previews can be embedded in note text, lists, quotes and tables, with
context-aware insertion and compact controls. Inspect the current model's
registered parts directly in notes or in a full inspection window, retaining
part selection and spacing in copied embeds.

Stability fixes isolate generated artifacts by source model, preserve generation
success across note-opening failures, reject stale insertions, and clean up
preview widgets and nested inspection windows. Local conversion failures and
renderer fallback handling are clearer. See `CHANGELOG.md` for each update.

Note insertion now separates the current location, actual dimensions and short
instructions. Display and size options have consistent labels and stack in narrow
windows. Light and dark themes use Obsidian's colors, with visible keyboard focus.

Model picker rows emphasize file names and keep full vault paths and format
labels. Searching by a folder path distinguishes models with the same name;
fuzzy highlighting, arrow-key navigation and Enter insertion remain available.

In-note part controls align selection, spacing, other geometry and copying.
**Copy embed** copies content to the clipboard; paste it into a note to preserve
the selected part and spacing. Part cards have clearer status labels and selected
states. The single-part button changes to **Show other parts** while active.
Chinese and English hints use shorter wording for registration and empty states.

Placement defaults, registered-part matching, stored configuration and renderer
routing remain compatible. The release contains the Obsidian installation assets
`main.js`, `manifest.json` and `styles.css`.

## 中文说明

本次发行包含自 0.8.1 以来的累计升级：笔记正文、列表、引用和表格中的模型嵌入，
按当前位置一键插入，以及按已登记零件进行正文展示和完整检查。稳定性修复涵盖
不同模型的文件隔离、笔记生成状态、预览清理、插入位置变化保护和渲染回退。

- 插入窗口顶部显示当前位置和实际尺寸，提示语区分主要操作与补充说明。
- 文件列表突出名称，保留完整路径和格式标签，方便区分同名模型。
- “复制嵌入内容”复制到剪贴板，粘贴到笔记即可保留当前零件选择和间距。
- 零件列表的状态和选中样式更清晰，单独查看后按钮变为“恢复其他零件”。
- 简化登记与空状态文案，窄窗口下自动调整布局，适配浅色和深色主题。
