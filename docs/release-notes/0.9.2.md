# AI Model Workbench 0.9.2

`0.9.2` stabilizes knowledge generation during model switches and optional UI failures.
It includes the 0.9.1 data-isolation fixes. Minimum Obsidian: `1.5.0`.

## Generation consistency

Live model evidence and screenshot data are captured synchronously before existing
artifact ownership is read. Switching models during those vault reads no longer
mixes another model's parts or screenshot into the original model's report.

Pending is recorded before reading existing files. If those reads fail, the run
records failure and releases its lock so the user can retry. Output paths are added
to final generation records once ownership resolution succeeds.

## Optional evidence and report opening

- Screenshot capture errors become analysis warnings. Reports, sidecars, indexes,
  and part drafts still generate from the remaining evidence.
- Generation success is committed after the required artifacts are saved.
- Failure to open a saved report shows a notice with the report path and preserves
  its successful generation record.
- A delayed report-opening failure from an older run cannot overwrite the status
  of a newer run.
