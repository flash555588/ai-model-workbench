# AI Model Workbench 0.9.4

`0.9.4` improves everyday inspection and knowledge navigation. It includes the
0.9.0–0.9.3 reliability and workflow changes. Minimum Obsidian: `1.5.0`.

## Clear tools and mode feedback

- More/Less has visible text and `aria-expanded`; extra icon actions display names.
  Tool groups wrap in narrow panes, including English labels.
- Active modes show persistent guidance and an Exit mode action. Exit returns to
  browsing without clearing completed measurements.
- Escape is scoped to the current preview or toolbar. During endpoint picking it
  cancels the pending point first; another Escape exits measurement. Focus,
  disassembly, slice, and annotation can also exit with Escape. Annotation editors
  retain their own Escape behavior. Escape on the expanded More entry collapses it.
- Measurement guidance distinguishes target selection, start point, end point,
  and starting another ruler. Mode feedback no longer duplicates a transient popup.
- Keyboard measurement exits annotation before activation. Returning to mobile
  scroll mode exits active inspection tools and retains completed ruler records.

## Adjustable workspace

Hide/show knowledge expands the model viewport without reloading it. The sidebar
retains its width when reopened. Pointer capture makes divider dragging reliable;
arrow keys adjust its width, Shift accelerates adjustment, Home or double-click
restores 200 px, and End selects the largest allowed width. Width bounds preserve
readable knowledge actions and reserve model viewport space. Resize resources are
released when switching models or closing the view.

## Knowledge navigation recovery

Opening a saved note can fail independently of generation. Its error appears next
to the knowledge actions while the persisted successful generation stays intact.
Open buttons follow vault create, delete, and rename events: missing artifacts
disable the corresponding action and explain regeneration; restored files become
available again. Existing user files and notes are not removed by the plugin.

## Verification

Local verification passed 404 unit tests across 58 files, TypeScript, lint,
settings migration, knowledge indexes, 36 browser scenarios, release assets,
and Obsidian 1.13.7 integration. The browser checks cover narrow English toolbars, measurement phase
guidance, and exiting with completed rulers. Real Obsidian checks cover sidebar
collapse, pointer/keyboard resizing, keyboard measurement, inline open errors,
and deleting/restoring or moving an index away and back in the disposable
verification vault. A mobile browser emulation checks 40 px toolbar targets,
scroll-mode exit, and retaining a completed ruler; rerun it with
`npm run verify:preview -- --rollout three-direct-glb --mobile-toolbar-only`.

Native touch-device usability and external CAD installations are outside this
local Windows run. The installation ZIP contains the three plugin assets;
preparing it does not publish a GitHub release.
