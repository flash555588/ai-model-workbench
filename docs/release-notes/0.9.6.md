# AI Model Workbench 0.9.6

Normal model wikilinks now behave like image embeds within a Markdown note.
Paragraphs retain the surrounding text; lists, quotes, and table cells retain
their parent structure. Reading view and Live Preview share the lazy renderer.
Existing `3d` code blocks retain their inspection layout.

`![[model.glb|240x180]]` sets width and viewport height in pixels. A width alone,
such as `![[model.glb|240]]`, uses a default 4:3 viewport. Omitted sizes use
400x300; supplied dimensions are bounded at 4096. Width fits the parent container.
Inside a Markdown table, write the separator as `\|`.

Headers are hidden on these image-style embeds. Controls and zoom appear on hover
or keyboard focus and remain available while inspecting; touch layouts show the
controls. Floating controls preserve the embed's layout size. Snapshot actions
continue to use the current plugin settings.

Source mode exposes the original syntax so dimensions can be edited. Inline and
fenced code, escaped embeds, and frontmatter remain text. Relative links use the
source note, with resolution caches isolated per note. Render children release
preview resources when reading sections are removed; CodeMirror retains ownership
of Live Preview widget roots. Standalone embeds use the editor's block layer to
avoid being covered by generic attachment cards.

Validation includes unit tests for parsing, sizing, escaped table separators,
relative-path isolation, code boundaries, and scan invalidation. Native Obsidian
checks cover all four placements, dimensions, source-mode editing, and Markdown
preservation. Hardware touch testing is outside this Windows run.

413 tests across 59 files, type checking, and lint pass. Native verification
passes on Obsidian 1.13.7 with Three and the default Babylon compatibility route.
Use `npm run verify:obsidian -- --clean --capture-note-ui` for the full run,
or add `--image-embeds-only --image-embeds-babylon` for the focused default-route
placement checks.

Minimum Obsidian remains 1.5.0. The local ZIP contains `main.js`, `manifest.json`,
and `styles.css`; it has not been published to GitHub.
