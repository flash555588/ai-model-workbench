# AI Model Workbench 0.9.8

Open a model file and choose **Show registered parts** in its right sidebar. The
inspection window splits the current single model according to its existing
registered part records, arranging parts in a catalog grid. Meshes belonging to
one part keep their relative positions and orientation.

Search by part name, toggle individual visibility, view one part alone, adjust
separation, restore the assembled model, or open a linked part note. Missing,
partial and conflicting references remain explicit. Unregistered geometry has a
separate visibility checkbox; it is shown initially when no record can be matched.
This feature does not infer new physical seams in a monolithic mesh.

Matching uses exact node paths/occurrence or component IDs and unambiguous mesh
references from the current model profile. It never uses cross-model similarity
scores to determine ownership. A uniquely identified group can recover capped
mesh references when its count agrees with the registration. Conflicting ownership
is rejected rather than moving geometry twice.

The dialog moves the existing loaded canvas instead of allocating another model
or renderer. It exits active tools and pauses animations during inspection. Close,
Escape, opening a part note or changing files restores geometry, visibility,
camera and animation state. Both default Babylon and opt-in Three are supported;
renderer routing and the minimum Obsidian version (1.5.0) remain unchanged.
