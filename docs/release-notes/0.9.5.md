# AI Model Workbench 0.9.5

`0.9.5` focuses on controls inside Markdown notes. It includes the reliability
and direct-view improvements from 0.9.0–0.9.4. Minimum Obsidian: `1.5.0`.

## Note controls

Reading code blocks and Live Preview embeds now share a model name/format header
outside the canvas and a compact toolbar. More expands View, Inspect, and Export
groups with names; active advanced tools remain visible after collapsing More.
Explicit viewport heights and container queries keep narrow note panes stable.

Pins means showing/hiding existing annotations. It starts pressed when pins are
visible and does not activate annotation editing, leave focus/measurement, or
change when inspection exits. Direct-view annotation editing keeps its existing
mode semantics. Measurement and slice details follow the active note task instead
of competing for inspector space; completed rulers are retained.

Live Preview uses the same controls, including mobile interaction/scroll mode.
Its remove action is omitted because the widget represents Markdown content.
Snapshot actions use the current settings forwarded through the lazy wrapper.
Toolbar disposal releases renderer observers, zoom resources, and host keyboard
handlers when the embed is removed, fails to load, or closes.
The lazy widget retains CodeMirror's owned root while mounting its runtime,
preventing asynchronous toolbar DOM from being interpreted as Markdown edits.
More never reveals hidden, unavailable capabilities or a handler-free remove action.

## Interactive display

Run `npm run preview:note-ui` to generate `ai-model-workbench-note-ui.html`.
It contains the actual project preview components, stylesheet, and GLB fixture;
no server or external model request is required. Width and theme controls show
the compact toolbar and expanded actions. Saving to a vault and removing a note
preview are disabled in this standalone showcase; use Obsidian for those actions.

## Validation

404 tests across 58 files pass, along with type checking and lint. The browser
preview suite passes 38 cases, and native verification passes on Obsidian 1.13.7.

Browser checks cover independent readonly pins, retaining active advanced tools,
and 320/360/480/720 px note frames on Babylon and Three. Real Obsidian checks
exercise reading controls and Live Preview controls and confirm that UI clicks
leave the Markdown content unchanged. The offline display checks light/dark,
narrow frames, mode exit, and absence of external network requests.

Native touch hardware remains outside this Windows verification run. The local
installation ZIP contains `main.js`, `manifest.json`, and `styles.css`; preparing
the archive does not publish a GitHub release.
