# AI Model Workbench 0.9.7

Image-style embeds now keep their small viewport clear. Hover or focus reveals
only Reset and Expand; touch layouts keep these two actions visible. Full view,
inspection, measurement and export controls are available in an expanded dialog.
Existing `3d` blocks retain their in-note toolbar.

Expand moves the same preview into the dialog, retaining its camera and completed
measurement records. The note reserves the original thumbnail size. Returning
exits active tools, restores the preview and focuses the Expand button. It does
not reload the model or create another renderer.

Enter on the canvas opens the viewer. Advanced shortcuts open their inspection
context before activating a tool. Escape first dismisses a tool or expanded menu,
then closes the dialog. Controls wait for successful model loading; widget disposal
also closes the dialog, including when Live Preview switches to source mode.
Reused Live Preview decorations render again when returning to the viewport;
obsolete async mounts cannot attach to an earlier widget lifetime.

Validation covers small table controls, unchanged paragraph/list/quote/table
placements, canvas identity, stable note dimensions, narrow dialogs, keyboard
opening/closing, Live Preview Markdown preservation and source-switch cleanup.
See the verification commands in `AGENTS.md`. The minimum Obsidian remains 1.5.0.

416 tests across 60 files, type checking and lint pass. Native Obsidian 1.13.7
verification passes on the default Babylon route and opt-in Three route; the full
run also covers note toolbars and direct-view knowledge workflows. Preview harness
checks pass for both note renderers and the default preview route.

The local ZIP contains `main.js`, `manifest.json`, and `styles.css`; this version
has not been published to GitHub. Physical touch-device testing is not included
in the Windows verification run.
