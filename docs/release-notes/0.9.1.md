# AI Model Workbench 0.9.1

`0.9.1` improves model data isolation and cleanup after failed resource loading.
It includes the 0.9.0 format-routing fixes. Minimum Obsidian: `1.5.0`.

## Knowledge artifact isolation

- Reports, analysis sidecars, and indexes check the source model of existing files
  before reuse. Same-named models get separate paths with deterministic suffixes.
- Unrelated user files remain intact; generated indexes retain user notes.
- Part drafts are reused only for the same source model and part ID, preserving
  manual edits. Different components with the same display name get separate drafts.
- Report folders are normalized, including output at the vault root.

## Conversion cache identity

- Source moves and identical basenames no longer establish cache identity.
- Untracked legacy adjacent outputs are not automatically adopted. Persisted
  records for the exact source can still reuse old output names.
- Hashed output names are checked against the source path, rejecting cache records
  contaminated by earlier relocation inference.
- New adjacent outputs include the original source extension, separating files
  such as `board.step` and `board.iges`.

Moving a source or losing an old cache record can require another converter run.
Existing converted files remain on disk and can still be opened directly.

## Failed resource cleanup

GLTF resource workers stop taking queued jobs after the first error and wait for
in-flight reads before revoking temporary Blob URLs. The original error remains
visible and successful reads retain the existing concurrency limit.

## Verification

Regression tests cover knowledge ownership, same-name collisions, edited notes,
source relocation, contaminated caches, and deferred GLTF reads after failure.
Release validation uses unit tests, TypeScript, lint, knowledge-index verification,
browser previews, the production build, asset hashes, and local Obsidian integration.

Verified on Windows on 2026-10-01: 384 unit tests in 55 files, TypeScript, lint,
settings migration, remote-draft privacy, knowledge index, diagnostics, all 35
browser preview cases, and the final build in Obsidian 1.13.7. The installation ZIP
contains only the three plugin assets and was checked against their SHA-256 hashes.

Install the verified `main.js`, `manifest.json`, and `styles.css` build assets.
Native mobile devices and external CAD installations are outside this local run.
