# AI Model Workbench 0.9.10

Use **Insert a 3D model in note** from the command palette or editor context menu
to insert at the cursor.
Choose a model and press Enter; the plugin writes the appropriate embed syntax.
Automatic dimensions are 240 × 180 inside text, 160 × 120 in table cells and
400 × 300 for standalone previews. Small, medium and large presets can override
these defaults. Table size separators are escaped automatically.

At an empty position, choose **Registered parts** to insert a persistent `3d`
block without writing JSON. Empty list and quote items retain their nesting on
every generated line. Within text or table cells, use the preview's Parts button;
saved part blocks are disabled there so insertion cannot break surrounding text.

The picker explains the current location and offers next steps for an empty vault.
When a model has no registration, the note shows the model and an **Open model to
register parts** action. Registration updates activate the original note preview.
Full note blocks use that inline entry instead of opening another empty dialog.

Cancel keeps the original text. A single Undo restores the insertion. Changing
the note, document or cursor while selecting a model requires reopening the
command; a delayed choice cannot write into another note. Code examples, note
properties and table divider rows are excluded. Existing embeds and advanced
configuration remain compatible, with no additional persisted settings or routing
changes.
