# AI Model Workbench 0.8.1

`0.8.1` is an Obsidian source-review compatibility patch for the `0.8.0`
precision-measurement and reliability release.

## Source Review

- Removed prohibited `obsidianmd/no-unsupported-api` and
  `@typescript-eslint/no-deprecated` suppression comments from the settings
  implementation.
- Guarded the Obsidian 1.13 declarative settings API with
  `requireApiVersion("1.13.0")` while retaining a plugin-owned imperative
  renderer for older supported Obsidian versions.
- Kept the minimum supported Obsidian version at `1.5.0`.

## Vault Access

- Documented the plugin's limited vault enumeration behavior. Model selection
  filters vault paths for supported 3D assets, and annotation heading search
  filters cached Markdown heading metadata.
- These scans are user-triggered. Note bodies are read only after the user
  selects a heading.

## Verification

- The Obsidian verification harness now opens the real settings window and
  checks that declarative setting rows and controls render in Obsidian 1.13.
- Temporary verification vaults are reset before setup and removed after both
  successful and failed runs.
- `0.8.0` measurement, preview, conversion, privacy, and renderer behavior is
  unchanged.
