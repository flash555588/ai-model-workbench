# AI Model Workbench 0.9.9

Registered parts now work in notes, with an inline catalog and a full inspection
window. Image-style embeds expose a **Parts** action while retaining their
paragraph, list, quote or table placement and dimensions. Expand to choose a
part, adjust separation or open the full part list.

Use a fenced `3d` block to retain the presentation after reopening:

````markdown
```3d
{
  "models": [{ "path": "models/model.glb" }],
  "height": 300,
  "parts": { "display": "registered", "separation": 100 }
}
```
````

`"parts": true` is shorthand for the full catalog. `parts.part` accepts an exact
registered ID or a unique full name; copied configurations use the stable ID.
Separation ranges from 0 (assembled) to 100 (catalog). `showUnregistered` controls
geometry outside registered parts. Missing or ambiguous selections remain
explicit. Open the source model to register parts when no records are available.
This feature uses existing registrations and does not infer physical seams.

Controls do not edit Markdown. **Copy display config** copies a complete block;
paste it into the note to persist the selection and separation. Full inspection
uses temporary state and returns to the inline selection and original canvas.
Registry updates refresh mounted notes. Switching to source mode or removing an
embed closes nested windows and releases the preview, including rendered table
embeds whose render-child unload callback may be delayed.

Both default Babylon and opt-in Three support the feature. Matching normalizes
the generated GLTF root wrapper without changing meaningful component paths.
Original assembly measurements, bounding boxes and annotation overlays are
hidden during part display and restored on exit. Renderer routing, model files,
registration records and the minimum Obsidian version remain unchanged.

Verification commands:

- `npm test`, `npm run typecheck`, `npm run lint`
- `npm run build`, `npm run verify:release`
- `npm run verify:preview`
- `npm run verify:obsidian -- --clean --note-parts-only`
- `npm run verify:obsidian -- --clean --capture-note-ui`

The installation package contains `main.js`, `manifest.json` and `styles.css`.
No GitHub release is created by this local update.
